# AIUsageIsland 1.19.14

当前交付为 macOS 14+、Apple Silicon 本地测试版，采用临时签名。它是独立第三方工具；ChatGPT 账号展示的是 Codex 额度及官方日统计，不代表 ChatGPT 聊天用量。公告订阅默认开启，已有开关选择保留。

1.19.14 修复精确贴住屏幕顶部边缘时无法触发浮窗的问题。上下相接的屏幕仍优先按鼠标实际所属屏幕判断，不越界唤出另一块屏幕。

1.19.13 将“显示屏幕 → 自动”改为任意屏幕顶部触发，进入哪块屏幕的顶部触发区，就在哪块屏幕弹出。固定浮窗及交互操作期间保持当前屏幕；全屏暂停按屏幕分别判断。

1.19.12 增加账号异常恢复动作、额度与日统计分别诊断、统一分析窗口的“消耗统计 / 额度变化”页签，以及“账号 / 外观 / 提醒 / 通用与支持”四组设置。历史 JSON 读写移到后台串行队列，磁盘失败保留内存数据；退出最多等待 3 秒，超时可能丢失最后一批尚未保存的采样。

安装：先退出旧实例，再打开 `releases/1.19.14/AIUsageIsland.app`。应用标识和数据目录保持不变。公告可在“提醒 → Codex 重置公告”关闭；自动提醒的暂停不会关闭公告订阅或取消已确认预约。

## 1.19.0：三平台用量分析（2026-10-06）

- 明细中的“今日消耗”提供鼠标悬停概览，点击行或图表图标打开独立分析窗口；纵向明细与账号页脚共用一行，三账号保持半屏范围。设置 → 账号与显示 → 管理 → 用量分析也可进入。
- 按账号自定义名称选择，支持最近 7/30 天日消耗柱形与完整连续 7 日均值折线。缺失日期留空、今日与缓存浅色显示，点击/悬停柱形或日期选择器查看当日明细。
- ChatGPT 使用本应用账号授权读取官方 Codex 账号日统计（profiles/me），不读取 Codex 授权、不按本地会话拼接、不把额度百分比换成 Token。官方日期未声明时区，当前暂按 UTC 解读并在界面注明。
- DeepSeek 展示缓存输入 / 未缓存输入 / 输出的堆叠柱形，费用和输入缓存命中率分开切换。命中率使用输入 Token 加权；费用直接使用平台官方金额，不使用现价回算历史分类费用。
- 智谱兼容旧套餐模型用量与积分套餐模型用量，仅使用真实 Token 字段。查询在各账号独立 WebKit 空间内完成，认证头、Cookie 不回传 Swift。身份延迟时以当前浏览器授权重新验证后再查历史。
- 数据按账号和平台隔离持久化，保留最多 90 天已返回的日期；短响应按日期覆盖并标记未返回的旧日为缓存，空响应和失败保留历史，删除账号清理。完整日均值不会跨缺口。
- Token 的概览、汇总、坐标轴、日详情全部直接使用既有 TokenFormatter.short（万/亿与截断），没有 M 或另外一套单位规则。

验证：临时账号/模拟官方响应的解析、身份变更、迟到身份、账号隔离、历史持久化与原生浅/深色渲染；未对当前登录的真实账号重新授权或调用其接口。真实响应变化与日界线仍需使用时确认；不支持的数据保留缓存并明确提示，不伪造零消耗。

接口字段依据： [Codex 官方 backend-client](https://github.com/openai/codex/blob/main/codex-rs/backend-client/src/client.rs)、[官方统计类型](https://github.com/openai/codex/blob/main/codex-rs/backend-client/src/types.rs)、[智谱官方用量插件](https://github.com/zai-org/zai-coding-plugins/blob/main/plugins/glm-plan-usage/skills/usage-query-skill/scripts/query-usage.mjs)、[智谱官方用量页面](https://bigmodel.cn/coding-plan/personal/usage)公开前端的旧/新模型用量字段及 Cookie/账号范围读取逻辑。

## 1.18.0：显示组合、设置迁移与本地趋势（2026-10-06）

- 平台能力统一：依据实际响应区分有限、无限、待确认和不适用，状态栏与提醒设置共用判断。Pro 无限 5 小时窗口仍可显示，有限周额度仍可设置阈值；智谱无周限制的窗口不触发周提醒。

- 设置 → 账号与显示 → 显示组合：保存最多 20 个自定义组合，包括最多四个账号及顺序、悬浮与明细布局；不改变登录、状态栏账号或提醒。组合里账号被移除后，应用前会提示重新保存。
- 设置 → 提醒与通用 → 诊断与配置：复制匿名诊断信息，导出或预览导入 JSON 配置。可选择外观、快捷键与提醒时段、账号显示与提醒等分组。账号必须手动对应不同的同平台本机账号；文件包含自定义名称，但不含 Token、Cookie、身份ID、登录状态或系统权限。不恢复登录项、通知权限和提醒总开关，同名显示组合将被替换。
- 设置 → 账号与显示 → 管理 → 查看趋势：查看过去 24 小时或 7 天的有限额度／余额曲线。仅记录成功读取的数据，最多 4000 个采样点；重置、补发、充值和长缺口分段。无限窗口不记录数值，历史从本版首次成功刷新开始积累；移除账号清理其趋势文件。

## 使用

1. 先将解压的 `AIUsageIsland.app` 放入“应用程序”文件夹，再双击运行。如 macOS 提示未验证开发者，在 Finder 中按住 Control 点击应用，再选“打开”。
2. 初次启动选择平台并登录。详情左下角的 ＋ 始终提供全部平台，同平台可以添加多个账号。设置 → 账号与显示中勾选最多 4 个账号，调整顺序、改名或移除；默认名称为平台名、平台名一、平台名二。取消显示保留登录，移除账号只清除该账号的本机授权与用量记录。⊖ 按自定义名称与平台列出已保存账号，确认按钮显示目标账号名称，仅移除所选账号。设置账号行也提供直接移除入口。升级保留已存授权；智谱旧共享网页会话例外，见上方登录隔离说明。
3. “显示屏幕 → 自动”模式下，鼠标进入哪块屏幕的顶部触发区，浮窗就在哪块屏幕弹出：内屏刘海区域、外屏顶部中央与缩略区等宽的区域均可触发。普通跨屏移动不会搬动浮窗；固定浮窗、设置、引导、登录或公告弹出卡片操作期间保持当前屏幕。指定屏幕模式仍只在所选屏幕触发。贴住屏幕最上边缘仍保持触发；移开后约 0.5 秒才收回，手抖移出不会瞬间消失。缩略区里每个选中的账号一格：DeepSeek 显示今日 Token 与费用，智谱与 ChatGPT 明确显示 5 小时与本周剩余额度（百分比）。点击可见缩略区展开详情。
4. DeepSeek 在系统临时授权会话完成官方授权，不要求填写 API Key，也不读取钥匙串。详情显示余额、今日／近 7 天／本月费用和 Token。成功授权后悬浮窗会自动置前并临时展开。只有主动点击图钉才会持续固定。
5. 智谱在应用内的 WebKit 窗口打开官方 CodingPlan 用量页并完成网页登录，不要求粘贴 CodingPlan API Key。成功读取额度后自动关闭网页登录窗口，详情显示 5 小时已用比例，以及 5 小时／本周的重置时间。这里显示的是套餐额度，不显示智谱按量计费 API 的余额或费用。当前智谱接口没有读取账号昵称，因此账号区域显示 CodingPlan 和平台返回的套餐等级。
6. ChatGPT 在系统临时授权会话完成 OpenAI 授权（PKCE + 本机 1455 端口回调），不要求 API Key，也不读取 Codex CLI 的 `~/.codex/auth.json`。详情显示 5 小时与本周已用比例、两个窗口的重置时间，以及套餐等级（账号区显示 `ChatGPT Plus` 这样）。额度用尽时卡片下方会出现橙色提示。多个平台同时显示时详情并排成多栏，每栏可单独登录和刷新。详情左上角标题：只显示一个账号时使用自定义名称，多个账号时显示「用量统计」，没有保存账号时显示「选择平台」。

程序启动时加载已连接平台，之后约每 5 分钟自动刷新已连接平台。鼠标悬停与刘海点击只展开界面，不触发网络刷新；离开浮窗后，0.5 秒内移回两侧数据不能取消收起，回到刘海触发区可重新唤出；需要即时更新时可点击刷新按钮。智谱启动时尝试恢复 WebKit 登录一次，未连接时停止后台重试，等待用户登录或主动操作。所有平台都退出后返回平台选择；右下角电源图标退出应用。

## 添加与移除账号

详情左下角的 ⊖ 旁有 ⊕ 按钮，始终可选择全部平台并添加账号。DeepSeek、ChatGPT 会启动系统临时 OAuth 授权会话；智谱使用账号独立的应用内官方网页登录空间。已有平台可以再次添加，显示位已满时新账号保留在设置列表中。智谱应用内登录窗高于设置页和顶部明细；从设置登录成功后留在设置页。DeepSeek、ChatGPT 使用系统浏览器授权时，应用窗口暂时降到普通层级，授权结束后恢复原层级，避免遮挡浏览器。

同平台允许添加不同账号，重复授权会提示已有账号名称。ChatGPT 按授权中的账号 ID（包括旧授权的 JWT 身份）及 Token 检查；DeepSeek 按 Token、资料中的账号 ID 及可读取的完整手机号／邮箱检查，兼容旧联系方式身份；智谱按官方页面的客户编号检查，并等待身份确认后完成新增。Token 变化不代表账号变化。DeepSeek、ChatGPT 无法确认新旧账号身份时，会提示验证失败并暂不保存此次授权，避免盲目新增重复账号；请先重新验证已有账号。DeepSeek 的可选账号 ID 字段兼容已通过样本测试，真实平台是否返回该字段尚未验证。被拒绝的新条目保留为未完成登录，可切换账号重试或移除，不会自动删除原账号。

添加和移除列表的整行均可点击，鼠标悬停时显示浅色圆角高亮。移除列表显示账号的自定义名称与所属平台，账号较多时可滚动。选择后先确认具体账号名称，只有点击「移除『账号名称』」才执行；取消保留账号。设置中每个账号行右侧直接提供「移除」，无需展开管理；卡片上的「移除账号」使用同样的单账号确认流程。

## 设置

### 状态栏组件

默认关闭，在设置中开启「显示状态栏图标」，并选择具体数据：DeepSeek 剩余余额、智谱 CodingPlan 的 5 小时／本周剩余额度、ChatGPT 的 5 小时／本周剩余额度。套餐图标中心使用平台 Logo，外圈表示剩余比例；DeepSeek 为左侧鲸鱼 Logo、右侧金额的紧凑组合。点击组件打开详情；鼠标移到图标不触发浮窗或提示，仍由原刘海区域触发。仅订阅已有数据，不另起网络刷新或持续旋转动画。

- 套餐余量 ≥20% 绿色，10%–20% 黄色，<10% 红色。
- 余额 ≥¥5 绿色，¥1–¥5 黄色，<¥1 红色。金额 ≥¥1 向下取整；<¥1 保留两位小数并向下取舍；大于零但不足 ¥0.01 显示 `<¥0.01`。
- 未添加、未登录、请求失败或没有选定的额度窗口时，显示灰色短横线；按选择的时间窗口匹配数据，不混用其他窗口。
- 状态栏按系统菜单栏外观适配，浮窗仍按应用设置的主题显示。


新增「外观」和「背景效果」：颜色可选浅色／深色／跟随系统，背景可选纯色／毛玻璃。默认深色＋纯色，保留升级前观感。悬浮条、详情、平台菜单和设置窗口统一使用所选主题；跟随系统会响应系统外观变化。毛玻璃使用 macOS 原生窗口背后模糊，系统开启「减少透明度」时回退纯色，但仍保留用户的毛玻璃偏好。


详情右上角的 ⚙ 打开独立设置窗口，始终位于浮窗之上。设置都会立即生效并记在本机：

1. **显示屏幕**：多屏时可选「自动」或指定某一块屏幕。自动的优先级是「带刘海的内屏 > 内建屏 > 第一块」。只连接一块屏幕时这一项置灰并给出说明。显示器 ID 会随插拔、重启变化，所以同时记下屏幕名字：ID 匹配不上时按名字唯一匹配，仍找不到就回退自动，而不是让悬浮窗消失。
2. **悬浮内容排版**：横向 / 纵向。横向是「刘海整行让位，卡片放到下方占满全宽」——**1 / 2 / 3 个平台高度完全一致**，加平台只多切一刀；纵向保持刘海宽度向下堆叠，窄但省高度。
3. **详情排版**：横向并排 / 纵向堆叠。横向适合对比；纵向适合窄布局，账号多时可滚动查看。

### 多平台排版规则

- **横向悬浮条**：宽度固定为 565 pt（刘海 + 两侧翅膀），卡片行按平台数等分。刘海那一整行不排数据。
- **纵向悬浮条**：宽度取刘海宽度（不低于 170 pt），每个平台两行指标。
- **横向详情**：面板宽度 `N × 220 + (N−1) × 12 + 38`，与悬浮条宽度解耦（单平台本来就是 360）。列宽下限 220 pt——实测 190 pt 时账号行就会被截断。窄屏上按屏幕宽度 80% 封顶。
- **纵向详情**：每个平台一张全宽卡片，指标横排。说明文字移到悬停提示以节省高度。
- **高度上限**：详情面板最高不超过屏幕高度的一半，超出部分滚动。按实测，堆叠排版到 3 个平台是 45.5%（14″ 内建屏），仍在限内。

多个平台的详情行放进**同一个 `Grid`**：每行高度取所有列的最大值，所以标题、大数字、指标行、说明、刷新时间、分隔线、账号区都逐行对齐，一侧多一行文案也不会让另一侧错位。内容异常增多时仍可滚动查看。

每个平台的说明文字必须短到在 220 pt 列宽（三平台时的下限）里只占一行，否则整行会被撑高，三平台详情比双平台高一截——`DetailLayoutTests` 会以「1／2／3 平台内容高度相同」失败来拦住这种改动。多平台详情顶部标题显示“用量统计”；只有一个平台时标题显示该平台名称。

双平台详情的高度不是写死的：它在运行时由内容实测高度加上顶部内边距推导（`IslandDetailGrid` 通过 `GeometryReader` 上报，面板随之增减），因此刘海屏与外接屏上的内容可用高度一致，不会一边贴边、一边留出一大块空白。改动详情行高或增删行时，需要重新运行 `Tests/DeepSeekIslandTests/DetailLayoutTests.swift` 并同步 `NotchLayout.dualContentHeight`。

Token 数以“万”“亿”显示：低于 1000 万用“万”，达到 1000 万后用“亿”；省略多余的小数零。少于 100 Token 显示为“<0.01万”，详情中悬停 Token 数可查看精确值。

程序还监听摄像头矩形中的鼠标按下事件：若 macOS 将该位置的点击交给应用或其他应用，点击黑色摄像头区域也能展开或收起。摄像头遮挡区域是否实际投递鼠标事件取决于系统和设备，代码与几何测试不能替代在本机上的实体点击验证。显示器目标使用 macOS 的内建显示器标记判断，并监听显示器配置变化；当前仅外接屏环境已实测顶部悬停唤出与移开收回，真实合盖／开盖切换仍需在机器上操作验证。

## 1.10.8 悬浮指标文案

鼠标悬停展开的紧凑浮窗中，智谱与 ChatGPT 改为「5 小时剩余」「本周剩余」，数值同时改为 100% 减去平台已用比例。例如已用 74% 显示剩余 26%。比例向下取整，不足 1% 但仍有额度显示 `<1%`，没有数据显示短横线。ChatGPT 实际为周／月窗口时保留正确窗口名称，不写死 5 小时。

## 1.10.7 重置时间附近补查

智谱与 ChatGPT 的 5 小时／周窗口在低余量（<20%）时，按平台返回的重置时间安排额外刷新：到期检查一次，尚未恢复则间隔 60 秒、120 秒各重试一次，最多三次。每 5 秒只检查本机计划，不意味着每 5 秒请求网络；仍遵守至少 30 秒的自动请求间隔，已有请求进行中时等待，所以到期检查可能延后数秒至约 30 秒。

两个窗口同时到期时合并为一次平台请求；普通五分钟刷新若恰好到期，也计入该窗口的检查次数。确认余量恢复后立即停止补查；平台先更新重置时间、稍后恢复额度时继续有限重试。断网／睡眠暂停，恢复后接着检查；移除或退出平台取消计划。没有重置时间、健康余量或启动时已过期超过五分钟的旧窗口不新增补查计划。

恢复通知仍须现有开关和对应指标开启，只有有效数据确认恢复才通知。三次补查结束后回到普通五分钟刷新，不无限重试。应用内更新与正式签名按本次用户要求暂不实施。

## 1.10.6 套餐额度恢复通知

现有通知开关扩展为「额度偏低或恢复时通知我」。沿用指标选择，智谱 CodingPlan、ChatGPT 的 5 小时／周窗口分别提醒。处于低余量（<20%）且经过重置时间后，确认余量增加才通知；额度用尽后重新有余量也会通知，即使接口没有返回重置时间。仅到时间、仍无额度、错误／离线缓存不通知。恢复通知说明平台、窗口和当前余量，点击打开详情。

同一恢复过程只提醒一次；平台先滚动重置时间、稍后才更新额度也能识别。状态保存在本机，启动、重新开启通知或重新选择指标只建立基线，不针对已有余量弹出通知。检查沿用约 5 分钟自动刷新，睡眠／断网时不请求，恢复联网后用有效数据确认；不会在预计时间凭空宣布额度恢复。DeepSeek 余额仍只使用原有低余额提醒。

## 日常使用功能（1.10.0）

设置新增「外观与布局」「提醒与通用」两个分页。后者提供开机启动、额度提醒与快捷键。

- **数据状态**：详情注明更新中、已更新、更新失败、离线或数据较旧，并保留最后成功获取的数据和时间。失败／离线缓存不会当作新数据触发提醒；超过 10 分钟的数据会标记较旧，菜单栏组件显示灰色未知状态。DeepSeek 余额成功但用量失败时分别保留余额与上次用量，并注明用量失败。
- **额度提醒**：默认关闭，开启时才请求 macOS 通知权限。可独立选择 DeepSeek 人民币余额、智谱或 ChatGPT 的 5 小时／本周剩余额度。余额跌破 ¥5／¥1、余量跌破 20%／10% 时发出本地通知；同级不重复，恢复后可再次提醒，同级通知至少间隔 30 分钟，升级到严重等级可立即提醒。启动、重新开启或新选指标时只建立基线，不针对已有低值发通知。去重状态保存在本机；点击通知打开详情。
- **登录 Mac 时自动启动**：默认不注册，开启后使用系统登录项服务，关闭后注销。页面显示系统真实状态；系统要求审批时显示「等待系统批准」，可点击进入系统登录项设置。建议将应用放在稳定的安装位置后开启。
- **系统恢复**：睡眠／离线时暂停自动请求，唤醒或恢复联网后只补刷新已连接且较旧／失败的数据，自动补刷新至少间隔 30 秒。切屏重新计算浮窗尺寸、重定位设置与引导并使旧动画失效；固定状态在切屏和唤醒后保留。
- **全局快捷键**：默认未设置。点击录制展开／收起、收起浮窗、刷新数据三组组合键；至少含 ⌘、⌃ 或 ⌥。Esc 取消，清除立即停用。组合键重复或注册时被其他应用占用会提示，替换失败保留原设置。快捷键使用系统热键接口，不需要辅助功能授权。

本版本通过模型、通知／登录项后端、真实热键注册与窗口绘制测试；未为验证而打开真实通知权限或注册真实登录项。实际通知弹出、系统登录项审批及实体合盖／唤醒仍需安装后在机器上确认。

## 数据来源

ChatGPT：`GET https://chatgpt.com/backend-api/wham/usage`，只带 `Authorization: Bearer <access token>`（可选 `ChatGPT-Account-Id`），与 Codex CLI、ChatGPT 网页版「用量」页同源。返回的 `rate_limit.primary_window` / `secondary_window` 各含 `used_percent`、`limit_window_seconds`、`reset_at`，Plus 的两个窗口是 18000 秒（5 小时）与 604800 秒（一周）；套餐在顶层 `plan_type`。

**窗口含义按 `limit_window_seconds` 判定，不按 primary/secondary 槽位**——Team 账号返回的是周 + 月窗口，界面标签会跟着窗口长度变成「本周／本月」。`rate_limit` 为 `null`（免费账号没有 Codex 额度）时显示「这个账号没有 Codex 额度」而不是解析失败。

令牌：`POST https://auth.openai.com/oauth/token`（JSON 体），授权页 `https://auth.openai.com/oauth/authorize`，用的是 Codex CLI 的公开 client，回调固定为 `http://127.0.0.1:1455/auth/callback`（被占用时退到 1457，两者都在该 client 的白名单里）。**本应用自己做登录，拿自己那份 refresh token**；OpenAI 的 refresh token 是一次性的，换一次作废旧的那份，所以绝不能拿 Codex CLI 的 `~/.codex/auth.json` 去刷——那会把用户的 CLI 挤下线。本应用完全不读那个文件。

智谱：在应用内打开官方 `https://bigmodel.cn/coding-plan/personal/usage`，监听页面自身请求的 `/api/monitor/usage/quota/limit` 响应。仅把客户编号（用于账号去重）、套餐等级、额度类别、5 小时／周额度数字、比例和重置时间从页面传给小组件；不会把请求中的 Authorization、Cookie 或其他登录凭据传给 Swift 代码。登录状态由本机 WebKit 网站数据维护，点击“退出登录”会移除 BigModel 网站数据。这个额度路径是网页内部接口，并非官方承诺稳定的开放 API；如果页面或响应结构变化，组件会显示错误而不是虚构额度。由于没有登录者的实测账号，本版本已验证解析样本与本机编译，但尚未验证真实登录后的完整网页流程。

智谱官方文档说明 CodingPlan 有 5 小时与周用量窗口，也提供用套餐 API Key 直接查询的方式。本程序按用户需求采用网页登录，所以需要官方用量网页正常加载并返回额度。

账号名称：DeepSeek 平台 `GET /auth-api/v0/users/current`。余额：`GET /api/v0/users/get_user_summary`。

用量：平台网页使用的 `GET /api/v0/usage/by_api_key/amount` 与 `GET /api/v0/usage/by_api_key/cost`，以本机时区的时间范围查询。Token 统计将缓存命中输入、缓存未命中输入、输出三类相加，不把 `REQUEST` 请求次数算作 Token。今日是本地今天 00:00 至明天 00:00；近 7 天包含今天及之前 6 个自然日；本月从月初到下月月初。

这些平台网页接口不是公开承诺稳定的第三方 API。当前用量解析根据已知网页请求结构实现，尚未用本账号的脱敏响应验证；网页登录授权能否访问这两个用量路径也尚未实测。若读取失败，今日 Token 显示“—”，费用显示带“≈”的本机余额差额估算，并在详情显示错误。不会把估算结果伪装成平台账单。

本机估算从首次记录余额开始。充值或余额增加不会计为负消费；赠送余额失效、充值与消费同时发生、两次刷新跨日等情况会使估算偏离实际。请以 DeepSeek 平台用量页和账单为准。

## 安全

程序不包含你在对话中贴出的 Bearer 凭据或 Cookie，也不会使用它们。若曾在公开或共享渠道贴出账号会话凭据，请退出该会话并重新登录，使旧凭据失效。

DeepSeek 网页登录返回的账号授权令牌保存在当前用户的 `~/Library/Application Support/DeepSeekIsland/account-grant`。目录权限为 0700，文件权限为 0600；点击“退出登录”会删除该文件，并尝试通知平台注销旧授权。这避免了旧版临时签名更新时重复索取钥匙串密码。它的保护弱于 macOS 钥匙串：以你当前用户身份运行的其他进程仍可能读取这个文件。智谱登录状态只存于 WebKit 网站数据，应用自身不保存智谱令牌。

旧版的 `com.deepseekisland.platform` 钥匙串条目不会被新版读取或迁移。若想清理它，可自行在“钥匙串访问”中搜索并删除。

ChatGPT 的 access token 与 refresh token 保存在同一目录下的 `chatgpt-grant`（同样 0700 目录 + 0600 文件；读取时校验属主与权限，并拒绝符号链接），点击“退出登录”即删除。程序**不读取** Codex CLI 的 `~/.codex/auth.json`，也不读取钥匙串里的任何条目。

开启额度不足通知后，首次获取的有效额度已不足也会提醒，不再只建立基线。智谱 CodingPlan 与 ChatGPT 的 5 小时、周额度分别判断：剩余低于 20% 提醒，低于 10% 可再升级提醒。同一已知周期、同一等级只通知一次，重启或重新连接不会重放；新周期可以重新提醒，不受旧周期冷却时间影响。旧版通知记录采用当前周期作为迁移基线。

总开关、单项选择、提醒时段和当天静默继续生效；缓存、连接失败和缺失额度不触发首次提醒。余额提醒采用同样的首次低值处理，余额的后续下降继续沿用冷却规则。


## 1.17.0：个人额度预约、自定义阈值与多账号

- **个人重置预约**：智谱与 ChatGPT 的有效 5 小时／周重置行可以点击，预约到点或提前 15 分钟的系统通知；低额度通知也有“重置时提醒我”。各窗口独立预约，重复确认不重复创建，设置可取消。由 macOS 调度，退出后仍可提醒。到点仅表示预计时间到了，不宣称实际恢复；恢复通知仍以有效额度增加为准。主动预约不受应用时段和当天静默影响，系统专注模式仍可能静默。时间缺失、过期、数据无效或非支持窗口不能预约。
- **通知阈值**：通用设置开启额度通知后可展开“自定义通知阈值”，按指标设置偏低／严重阈值、保存或恢复默认。严重值须大于 0 且小于偏低值，百分比不超过 100。图标颜色仍采用原标准；实际恢复通知也使用所选偏低阈值建立等待恢复状态。周期去重与重启去重保持。
- **设置整理**：关闭状态栏时收起指标与样式；额度通知关闭时收起其指标与阈值。官方公告共用的提醒时段／静默仍可操作。账号管理、阈值默认折叠；预约列表不依赖自动通知总开关。设置顶部概览显示已添加平台数及状态栏开关。
- **多账号**：已保存账号数量不受显示位限制，最多同时显示 4 个；每个显示账号独立刷新。原账号沿用原授权目录，新账号以平台与 UUID 独立保存授权和费用记录，CodingPlan 使用独立 WebKit 数据空间。DeepSeek、ChatGPT 每次创建临时授权会话，登录入口不主动复用普通浏览器登录态；实际隔离由系统与支持临时会话的浏览器执行。ChatGPT 按授权账号标识与令牌检测重复，DeepSeek 按官方资料中的完整邮箱／手机号检测重复；身份信息不足以确认账号归属时拒绝保存并提示验证。重新授权不会静默替换可识别的原账号身份。刷新令牌按账号串行轮换，正在轮换时不能转移该账号的运行状态；隐藏不丢弃在途的新令牌。个人额度提醒按账号独立保存，菜单栏账号在“账号与显示”中按自定义名称选择；切换账号不会取消其他账号的预约，显示顺序不变。

首次引导同步补充多账号、个人预约及阈值说明。验证采用模拟通知后端和临时凭据，未启动第二个真实账号实例；真实多账号授权和系统通知投递仍需安装后确认。

## 多账号显示与实际尺寸预览

设置窗口默认内容区为 480 × 680 pt，配置列表可以滚动，不在设置内嵌完整明细。点击底部“预览悬浮”或“预览明细”，在目标屏幕顶部查看真实岛形；两套横向／纵向排版独立保存。预览时设置窗口移到岛形下方，空间不足时缩短到可用高度，账号列表仍可操作。四账号横向明细在 1512 pt 内屏上宽 954 pt；纵向明细受半屏高度上限约束，必要时滚动。

### 多账号菜单栏取值

顶部仅显示一个状态栏图标。设置“账号与显示 → 状态栏账号”按已设置的自定义名称选择账号，开关也在此处；额度窗口（5 小时／本周）与样式在“外观与布局 → 状态栏”选择，各项独立保存。旧版只有平台的设置升级时会选择该平台已有数据的账号；明确选定账号后，新增、登录、改名及个人提醒账号切换都不会替换它。隐藏该账号的悬浮卡片仍继续刷新状态栏数据。删除所选账号后配置会改选剩余账号，设置和右键菜单同步显示名称。

已选择账号未登录、更新失败、离线或没有对应额度窗口时显示未知，不借用其他账号的额度。圆环／水位表示剩余量，已用 50% 对应剩余 50%；未知中心显示问号，与真正剩余 0 的红色状态区分。自动关注只比较所选账号的额度窗口，不切换到别的账号或平台。

鼠标悬停和右键菜单明确显示账号名称、额度窗口及余量。右键“选择账号”与设置同步，未完成登录或首次更新的条目禁用；刷新操作针对当前圆环使用的账号。状态栏选择不改变个人提醒设置；在“提醒与通用 → 余额与额度提醒”按账号名称配置提醒。


## 账号用途与独立提醒

- “账号与显示”列出每个账号的连接状态及用途：是否显示、是否用于唯一的状态栏图标、提醒是否开启或暂停。名称完全由用户自定义，不推断工作或个人身份。移除和排序操作继续保留。
- “提醒与通用”的额度提醒按账号名称配置：低余量、实际恢复、额度窗口和自定义阈值分别保存。账号改名或切换显示不改变提醒设置。总开关暂停所有账号的自动额度提醒，共用时段和当天静默；官方公告开关独立。
- 隐藏但开启提醒的账号继续刷新；同平台、同窗口的多个账号分别通知和预约。点击通知打开对应账号详情，不改变显示选择。移除账号只清理该账号的提醒配置、通知和个人预约。
- 升级时原平台提醒配置只迁移给该平台当前账号；其他账号和后续新账号默认关闭提醒。旧预约记录兼容读取，切换账号不取消已有预约。

设置窗口保持 480×680 pt，长内容滚动。额度卡片与官方重置动态的原有展示保持不变。验证使用临时账号数据与模拟通知后端，真实 macOS 通知投递仍需安装后确认。

### Pro 的 5 小时无限制

ChatGPT 用量仍读取 `/backend-api/wham/usage`。已识别的 Pro 套餐成功返回周额度、且未返回有限 5 小时窗口时，显示「5 小时额度：无限制」，悬浮条显示「无限制」，状态栏对应指标显示 ∞，不设置该窗口的低额度提醒或重置预约。周额度继续显示实际百分比与重置时间。接口若返回有限 5 小时窗口，以真实数据为准；其他日／月有限窗口保留显示，并单列 5 小时无限制说明。缺失套餐、空 rate_limit 或损坏窗口不解释为无限制。

规则参考 [OpenAI 当前 Work/Codex 用量说明](https://help.openai.com/en/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex)。本次使用构造响应验证 Pro 单周窗口，未重新授权或读取用户 Pro 账号的真实响应。

### 智谱只有 5 小时额度的套餐

额度解析不再强制要求周窗口。成功响应中存在有效 5 小时额度、但没有周额度条目时（例如 V1），悬浮与明细显示「无周限制」，周重置显示「无需重置」；选择周额度的状态栏显示 ∞，该窗口不安排低额度／恢复提醒或重置预约。5 小时额度的比例、重置和耗尽提示继续生效。有周窗口的套餐保持原显示。判定以实际响应为准，不按 Lite／Pro 等套餐名写死版本；出现周条目但内容损坏时仍报读取错误，未登录或尚无有效额度响应时仍显示未知。

本轮测试使用只有 5 小时窗口的构造响应，未重新登录用户智谱账号。
