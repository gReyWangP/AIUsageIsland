# Security Policy

## Supported versions

Only the latest 1.x release receives security fixes.

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting** (Security → Advisories) for this repository. Do not open a public issue containing access tokens, cookies, account identifiers, Bark addresses, or unredacted API responses.

## Data and scope

The app stores platform credentials locally and does not collect telemetry. See [PRIVACY.md](PRIVACY.md) for the data model. Third-party platform behavior is outside this project's control.
