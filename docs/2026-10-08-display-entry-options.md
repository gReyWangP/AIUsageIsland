# 显示入口与状态栏卡片

本地版本 1.19.16 / build 65。设置 → 账号 → 显示入口与状态栏账号中提供三个独立选择：顶部中央移入、状态栏图标、状态栏移入预览。中央移入默认开启，状态栏移入默认关闭；既有图标显示偏好保留，隐藏图标保留移入偏好。

状态栏预览停留 0.3 秒展开，离开按钮和卡片 0.4 秒收起。点击固定，再次点击或点击外部收起；点击展开后按 Escape 收起。右键及 Control 点击保留快捷菜单。卡片不随鼠标移动，使用原生 NSPopover 锚定按钮；内容读取状态栏当前账号的现有运行模型，不创建额外轮询。刷新、分析及设置沿用当前账号和既有窗口。

设置及引导暂停自动预览，不关闭明确点击固定的卡片。中央全屏暂停不影响可见状态栏按钮；登录或睡眠期间关闭卡片。两个显示入口都关闭时，重新打开应用进入设置；中央关闭且无账号时，完成引导后进入设置。

验证：swift test 共 472 项，2 项按既有条件跳过，0 失败。跳过项分别要求主动联网公告探测、显式提供匿名真实日统计缓存。覆盖默认值和持久化、停留和跨间隙、点击固定及外部关闭、设置打开时保持、Escape、中央关闭后的启动入口。三平台两种外观原生渲染通过，实际两块屏幕的右侧边缘原生锚点定位通过。原生状态栏在另一块屏幕的系统复制按钮、自动隐藏菜单栏及真实全屏 Space 切换尚未执行人工验收；另一应用处于前台时的被动预览不拦截该应用的 Escape。
