# 自动屏幕触发（1.19.13 / build 62）

按用户确认，修改现有“自动”模式，不新增“跟随鼠标”选项。鼠标进入任意屏幕顶部触发区时，同一个浮窗迁移到该屏幕；普通跨屏移动不会搬动浮窗。指定屏幕选择保持原有语义。

## 行为与边界

- 有刘海屏幕使用摄像头开口区域；无刘海屏幕使用顶部中央触发区。触发区受所属屏幕边界限制，避免上下排列屏幕的越界触发。
- 固定浮窗、设置、使用引导、登录及公告卡片操作期间保持当前屏幕。屏幕参数改变时按显示器 ID 保留仍连接的屏幕；断开后按鼠标所在屏幕或内建屏优先级回退。
- 切屏更新刘海、锚点、尺寸上限，失效旧动画回调，不创建重复面板。设置使用浮窗的当前屏幕；引导重新定位保留自身仍连接的屏幕。
- 全屏暂停按目标屏幕判断，检测结果分别缓存 1 秒；屏幕几何变化不沿用旧结果。
- 自动模式启动或用户显式切回自动时，先定位鼠标所在屏幕。账号、偏好和存储格式不变。

## 验证

新增测试先复现错误后修复：外屏触发、普通移动、固定/交互屏幕保留、上下排列屏幕边界、菜单栏排除、空屏幕、屏幕移除回退，以及独立全屏缓存。

最终 `swift test`：451 项，2 项跳过，0 失败。跳过项为需要显式启用的公告联网探针和真实日统计样本。构建安全脚本与 Bash 语法检查通过。独立代码审查指出的拓扑保留、上下屏幕触发和引导位置问题已处理。

本轮未启动或替换用户正在运行的应用。真实多屏、全屏空间、屏幕插拔及边缘触发手感仍需安装测试；自动化测试使用屏幕几何夹具，不等同于多屏实机验收。

## 安装验收

退出旧实例，打开 `releases/1.19.13/AIUsageIsland.app`，在外观设置中选择“显示屏幕 → 自动”。依次将鼠标移到各屏幕顶部中央（刘海屏为摄像头开口），确认浮窗只在目标屏幕出现。普通跨屏移动保持原位置；固定、设置和登录期间不自动切屏。上下排列屏幕时检查边界；拔掉当前屏幕后确认可在剩余屏幕触发。

产物验证：Release 编译通过（45.34 秒）；独立应用校验通过（1.19.13 / build 62，arm64，local）；安装 ZIP 完整性通过。版本目录保留应用、安装 ZIP、源码快照、SHA256 和测试/构建日志。
