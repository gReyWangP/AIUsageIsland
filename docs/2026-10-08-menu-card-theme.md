# 状态栏卡片主题修复

1.19.16 卡片只设置了 AppearanceMode，没有读取 BackgroundEffect；NSPopover 自带系统材质，导致中央纯色、状态栏毛玻璃。旧渲染测试给内容手工加背景，遗漏了真实窗口底层。

1.19.17/build66 改用透明、非激活 NSPanel，卡片复用 IslandBackground 和中央主题设置；默认深色纯色不再有系统材质，选择毛玻璃时使用原有 behindWindow 模糊，减少透明度设置继续回退纯色。原有预览、点击固定、外部点击与 Escape、账号和操作回调保持。窗口锚定图标，由既有指针计时器同步图标位置，几何不变时不更新窗口。

实际窗口回归先失败后通过：深色纯色背景 alpha=1/red=0，浅色 alpha=1/red≈0.97，与中央背景一致；纯色没有视觉效果子视图，改为毛玻璃时创建共享视觉效果视图，卡片保持可见。移除旧测试的人工背景。真实两块屏幕右侧边缘和锚点移动、点击固定与悬停禁用、Escape 收起、三平台两种外观原生内容验证通过。真实全屏 Space、系统复制状态按钮与自动隐藏菜单栏仍未人工验收。

swift test 共 473 项，2 项按原有联网探测／匿名真实统计条件跳过，0 失败。三个发布脚本检查通过。独立审查提出的锚点移动回归已修复并增加原生验证。发布说明只包含功能项和安装说明。

Release 编译及应用产物校验通过。已发布 GitHub v1.19.17 并同步公开 HTTPS appcast，build66、签名、包长度和 GitHub 资产摘要核对一致。ZIP SHA256：307fad90a936d451f5257be7b5aa7e9d32f147f59e738eda25b879c297dcbe0b。已有客户端可使用检查更新升级；未覆盖用户运行中的应用。
