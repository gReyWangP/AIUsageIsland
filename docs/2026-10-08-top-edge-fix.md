# 精确顶部边缘触发修复（1.19.14 / build 63）

用户反馈 1.19.13 鼠标直接移到顶部边缘无法触发浮窗。根因是新加的 `NSRect.contains` 屏幕归属判断不包含 `maxY`。之前的测试只检查顶边内一像素，遗漏精确顶边；本轮以精确顶边测试复现 5 个失败，包括内屏/外屏直接唤出、自动切屏以及初始定位。

修复共用屏幕归属判断：先选择矩形实际包含鼠标的屏幕，没有屏幕包含时，再接受横坐标范围内的精确顶边。上下相接的边界优先归属上方屏幕，不唤出下方浮窗；上方屏幕断开后下方屏幕顶边恢复触发。所有屏幕信息传入普通悬停、隐藏快捷键退出等待和动画完成后的唤出判断，避免只修切屏而遗漏当前屏幕触发。

专项 ScreenTargetTests 13 项通过。独立审查确认触发路径完整，共享边界不受屏幕数组顺序影响。未启动或替换用户正在使用的应用，真实多屏鼠标边缘行为仍需安装验证。

最终全量 `swift test`：454 项，2 项跳过，0 失败。跳过项为需要显式启用的公告联网探针和真实日统计样本；构建安全脚本和 Bash 语法检查通过。

Release 构建成功，独立应用校验与 ZIP 完整性校验通过：1.19.14 / build 63，arm64，本地临时签名。版本目录保留应用、安装 ZIP、源码快照、SHA256 以及测试/构建日志。
