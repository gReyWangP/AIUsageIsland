## 存储实现与性能

保持既有 JSON 文件名、账号路径与数据口径。展示 Store 在 MainActor 更新内存；HistoryPersistence 的串行后台队列负责限量读取、编码、原子写入和删除。同一次额度刷新先更新各指标，最后提交一次采样集合；排队保存按文件合并最新版本。

启动读取先入队。刷新先返回时，迟到历史只补充旧日期/采样，不覆盖新值；旧账号 Store 失效后拒绝新保存和加载结果。清理排在进行中的写入之后，避免旧写入复活账号目录；新账号实例的读写排在清理之后。账号目录清理失败会显示独立提示。

正常退出先阻止新的历史更新，等待启动加载和排队保存。3 秒后无论磁盘是否完成都允许退出，只回复一次；原子保存保留上一有效文件，新近内存数据可能未落盘。强制结束进程不保证收尾。

同机调试构建的历史概览/曲线准备基线约 0.024 秒，变更后约 0.024 秒，均低于测试的 250 毫秒预算。慢盘测试用阻塞队列验证更新内存不等待 I/O。这不是鼠标点击到显示的端到端测量；真实网络、慢盘设备、睡眠恢复仍需本机手动测试。

## 本地验收操作

1. 退出旧实例，打开独立版本目录的应用；核对版本 1.19.12 / build 61。
2. 检查旧账号、显示组合及提醒偏好保留。引导完成后再次启动不自动弹出；可在设置重开。
3. 对一个已登录账号打开分析，切换两个页签和账号，删除当前账号后确认选择回退或空态；检查缓存、来源和时间。
4. 在提醒页检查暂停作用范围、公告独立开关，验证已确认预约可取消；系统通知权限、横幅及专注模式另行检查。
5. 确认普通分析窗口可切换桌面，多屏与全屏下位置合理；睡眠恢复后时间与缓存状态正确。
6. 通过账号管理移除测试账号，检查授权和对应历史清理；勿使用真实账号做破坏性验收。

本轮自动化证据与包校验结果将在完成后记录于下方。真实登录样本和公开公告联网探针仅在显式提供条件时运行，跳过不计作实测通过。

回退：保留 1.19.11 产物和实施前源码快照；不要在运行实例上覆盖文件。账号凭据路径未迁移，历史格式兼容；启动偏好迁移尊重已保存选择。当前目录无 Git 元数据，未创建提交、PR 或发布流水线。Logo 仅标识平台，来源记录见 LogoSources.md；商标使用许可仍属于公开发布前核实事项。
