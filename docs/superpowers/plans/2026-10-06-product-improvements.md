# 逐项产品完善实施计划

> 执行方式：当前会话直接实施；按用户已批准的功能说明逐项推进，不重复要求许可。每项先回归测试，最终只读复审与 release 验证。

目标：平台规则一致、失败刷新可控、问题可诊断，提供显示组合、无凭据设置迁移和有效额度趋势。

全局约束：macOS 14 / Swift 6；保留账号 UUID 与凭据目录；不运行第二个生产应用，不重新授权真实账号；不用昵称自动关联导入账号；最多四个显示账号；正式签名/更新暂缓。

- [x] 平台能力：新增 PlatformCapabilities.swift。AccountRuntime 用实际 quotaWindow 描述余额/有限/无限/未知/不支持；菜单、提醒和阈值设置复用，重置必须有有效时间。测试 Pro 无限5h、V1无周、未知、真实有限窗口。
- [x] 失败重试：新增 RefreshPolicy.swift。按账号记录失败退避，平台级并发最多2；取消不增加退避、成功清零、授权故障不自动重试；人工刷新遵守限流冷却。接入 runtime 的自动/手动入口及智谱异步回调。测试退避上限、成功/取消、并发释放及旧账号结果。
- [x] 诊断：新增 Diagnostics.swift 与设置入口，白名单生成平台/匿名序号/连接/新鲜度/安全错误代码/成功时间；不导出名称、完整ID、Cookie、Token、URL或底层文本。测试危险字段不可泄露。
- [x] 显示组合：新增 DisplayPreset.swift 及账号设置入口；保存名字、最多4个账号、两种布局；应用前检查不存在账号并明确提示；不改状态栏/提醒/登录。测试排序、缺失账号、持久化。
- [x] 设置迁移：新增 SettingsTransfer.swift 与预览设置入口。版本化 typed JSON，白名单外观/快捷键/提醒时段、匿名编号账号偏好、组合；按平台手动关联本机账号，分组应用、不导入权限/凭据/显示器ID；全部验证后应用。测试格式版本、阈值/快捷键/四位上限、无凭据、映射重复/跨平台、原登录不变。
- [x] 趋势：新增 UsageTrend.swift 与账号趋势窗口。按成功时间记录有限额度和周期，持久化有限数量，24小时/7天图；缺口、周期重置分段，恢复不能解释消费。测试去重、上限、周期分段、非新鲜/无限不入库。账号移除清理。
- [x] 全量测试、只读复审、打包；记录哪些真实平台/系统行为尚未验收。

审查重点：异步生命周期与取消、隐藏账号、比例/时间非法值、导入重复关联、缓存不可进入趋势或通知。目录无 Git，操作前保存源码备份到临时目录；不伪称已提交。
