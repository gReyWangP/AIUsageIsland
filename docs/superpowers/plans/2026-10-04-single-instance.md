# 启动单实例保护

用户授权测试并自主推进。真实测试观察到同 bundle ID 的旧 dist 与临时测试版可以并发运行，共用凭据目录。先补启动保护，不声称能让未升级旧版本主动服从锁。

设计：初始化 AppDelegate/IslandModel 之前，检查同 bundle ID 的更早运行实例，已有实例则激活并退出；新版本另外通过凭据根目录的 flock 互斥，持有到进程结束。无法建立锁则拒绝启动并显示说明，不继续读写凭据。锁文件不存 token，不删除锁文件，崩溃由 OS 释放。

- [x] 写入 ApplicationInstanceLockTests（互斥、释放后重获、保留空锁文件、symlink 拒绝）。
- [x] 实现 ApplicationInstanceLock.swift 并接入 main.swift，在模型初始化前处理已有运行实例。
- 后续用户明确要求停止当前会话测试：不继续全量测试、独立审阅或 release 打包，不据此宣称启动保护已完成验收。

限制：先运行新版再启动不含保护的旧版，旧版不会遵守新锁；需要退出旧版并使用同一新版。浏览器网页登录 A/B 最终身份验收需要用户实际登录。
