# 日常使用优化实现清单

> 执行方式：在当前会话逐项实现并验证。用户已批准下列五项，不新增用量历史范围。

目标：提高数据可信度，提供可控的额度提醒、自动启动、系统恢复与快捷键。

约束：macOS 14+；保留原 OAuth／网页登录与五分钟轮询；鼠标不请求网络；提醒默认关闭；登录启动默认不注册；快捷键默认未设置；不重置引导偏好；提醒只使用成功数据，不使用失败缓存。

- [x] 数据状态：新增 DataFreshness，区分更新中、成功、失败缓存、离线缓存、较旧、未登录；保留最后成功数据与时间。详情两种排版和紧凑视图均提示状态。测试离线、失败、更新中、过期和部分用量失败。
- [x] 额度提醒：每个已连接平台的余额及 5 小时／周窗口独立去重；20%／10%，CNY ¥5／¥1；同一阈值恢复后重新武装；启动与重新开启只建立基线；跨重启持久去重；首次打开开关才请求通知授权；错误缓存不通知。测试穿越、反复刷新、恢复、低值基线与无效数据。
- [x] 登录启动：使用 SMAppService.mainApp，显示系统真实状态、待批准与错误；仅用户开启时注册，关闭时注销。可打开系统登录项设置。测试后端成功、失败及待批准，不改变真实系统注册。
- [x] 系统恢复：监听睡眠／唤醒与 NWPathMonitor；离线／睡眠暂停自动请求，恢复仅补刷新已连接且较旧／失败的数据；自动重试至少间隔 30 秒。切屏重新计算尺寸缓存、清理旧动画并重定位设置／引导。测试恢复节流与多屏几何选择、旧动画失效。
- [x] 快捷键：Carbon 全局热键，不需要辅助功能监听；可录制展开／收起、收起、刷新三组快捷键；至少含 Cmd/Ctrl/Option；拒绝重复与系统占用；清除立即注销；持久保存。测试验证、持久化、注册失败与替换。
- [x] 设置与交付：外观／布局、通用／快捷键两个页；保持内屏可见高度；引导补充新功能入口；完整 swift test、release .app、签名校验与源码包。

验证限制：系统通知权限、登录项审批、实体合盖／唤醒、系统级快捷键占用须在真实已安装应用环境确认；不为测试自动启用用户的系统设置。

验证记录：完整 swift test 167 项通过；原生设置窗口浅／深色出图确认；真实 Carbon 热键冲突与注销测试通过。发布包构建与签名校验另见交付日志。
