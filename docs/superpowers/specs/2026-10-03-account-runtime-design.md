# 账号生命周期与稳定运行实例

用户已批准产品评估中的渐进改造方向。本轮交付账号生命周期与运行模型，不新增平台、趋势、签名或更新系统。

## 目标与约束

保持 macOS 14、Swift 6、无第三方依赖和现有界面。保留账号 UUID、legacy 数据目录、偏好键、通知 ID，升级不要求重新登录。一个账号始终拥有一个 AccountRuntime；显示、重命名和当前账号选择只引用它，不复制或转移数据、网络请求及 WebKit 会话。IslandModel 管理目录、显示和编排；AccountRuntime 管理单账号认证、数据和轮询；现有平台客户端保持行为。

## 方案选择

采用渐进提取 AccountRuntime。仅拆 extension 无法消除状态搬运；同时重写所有平台适配器和持久化会扩大迁移风险。先移除完整 IslandModel 的递归复用，保留现有平台字段作为兼容接口，后续再用统一业务指标替换。

## 生命周期

删除前捕获准确账号 ID；成功清除凭据后更新目录并通知清理。失败保留账号并给出错误。删除未选中账号不触发登录、刷新或改变其他账号运行状态。保持同平台刷新/登录中的管理保护，避免令牌轮换时删除。保留登录取消版本保护。

所有需监测账号（可见、状态栏、开启提醒）的后台轮询与网络恢复均由同一集合驱动。隐藏且无用途的账号暂停新请求，已在途的轮换允许完成并保存。账号选择不触发网络请求。断网与睡眠继续暂停刷新。所有快照、通知、菜单栏消费对应 AccountRuntime。

## 验收

完整删除链路清除最后一个非 legacy 账号的提醒策略和预约；其他账号不受影响。切换选择后仍为同一个运行实例且保留快照；切换没有额外请求。未监测的当前账号不继续自动刷新。网络恢复覆盖隐藏提醒账号。旧授权身份、竞态、菜单栏、通知、布局测试保持通过。

## 后续边界

平台能力抽象、统一业务指标、结构化错误、跨进程保护、诊断与正式发布另行实施。本轮不承诺解决所有产品评估条目，不更改真实用户授权、不启动第二个应用实例。
