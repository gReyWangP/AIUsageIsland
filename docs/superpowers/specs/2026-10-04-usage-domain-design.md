# 业务指标与额度窗口统一

## 重新核对后的范围

开始前重新读取当前源码、近期文档与测试；已有 AccountRuntime 重构以及新增 ChatGPT Pro 无 5 小时限制功能。以当前代码为基线，不覆盖后续修改。用户已授权继续完善，本轮在既有架构方向上执行。

## 设计

从 MenuBarStatus 提取 Foundation 业务类型 UsageMetric、UsageReading；保留 MenuBarMetric/MenuBarData 别名作为旧 UI/测试兼容入口。指标 rawValue、Codable 结构、配置键、通知 ID 不变。窗口长度由枚举分支定义，不再通过中文标签判断；余额没有额度窗口。

增加统一的 QuotaWindowState（有限、无限、缺失）与经过验证的有限窗口值。AccountRuntime 按账号所属平台及真实窗口秒数查找，有限值优先，保留当前 Pro 无限窗口判定；不得把缺少窗口当作 0 或无限。非法百分比拒绝，非法重置时间不产生补查或预约。余额、百分比和无限保持不同业务类型。

运行实例提供业务读数，菜单栏只是展示消费者；提醒阈值、通知、预约与自动补查依赖业务类型及统一窗口读取。快照仍保留不同平台的展示布局，任意日/月窗口继续按原解析结构显示，不强行映射成 5 小时或周。

## 验收

现有 Pro、有限窗口、其他窗口、账号隔离、提醒去重与布局回归全部通过；旧偏好与预约 JSON 可读取且写回保持值；负数/非有限百分比不形成健康读数；非有限日期不用于调度；无限窗口无阈值与重置预约，周额度耗尽仍受限。

## 边界

本轮不改平台认证/HTTP 接口、不新增平台、不处理全套结构化网络错误或签名发布。不启动真实账号应用实例。下一轮平台适配层可以消费本轮业务类型。
